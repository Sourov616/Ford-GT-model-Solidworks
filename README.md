<h1>Ford GT (2019) – 3D Vehicle Modeling Using SolidWorks</h1>

<h2>Overview</h2>
<p>
This repository contains a detailed 3D CAD model of the <span class="highlight">Ford GT (2019)</span>,
developed using <span class="highlight">SolidWorks</span> as part of the
IPE 204: Engineering Graphics and Introduction to CAD Sessional project submission. 
The project demonstrates the application of engineering graphics principles and CAD modeling techniques 
to recreate realistic vehicle geometry based on publicly available references.
</p>

<h2>Project Description</h2>
<p>
The modeling process involved creating individual components through parametric part modeling 
and assembling them using appropriate mating relationships to maintain dimensional consistency and structural coherence.
The focus was on geometric accuracy, proportional correctness, and organized assembly structure rather than manufacturing-level detailing.
</p>

<h2>Project Components</h2>
<ul>
    <li><span class="highlight">Parts:</span> Individual vehicle components (.SLDPRT files)</li>
    <li><span class="highlight">Assembly:</span> Complete vehicle assembly (.SLDASM file)</li>
    <li><span class="highlight">Renders:</span> Isometric and side-view rendered images</li>
    <li><span class="highlight">Video:</span> Exploded view animation showing component arrangement</li>
</ul>

<h2>Software Used</h2>
<p>SolidWorks</p>

<h2>Key Highlights</h2>
<ul>
    <li>Parametric part modeling</li>
    <li>Mate-based assembly constraints</li>
    <li>Rendered images for visualization</li>
    <li>Exploded view animation for component-level understanding</li>
</ul>

<h2>Repository Notes</h2>
<p class="note">
Files are organized for clarity and easy navigation. The exploded view video demonstrates assembly sequence and structure.
</p>
